SpectraWeb

Client-side invisible script interceptor, built by Team NIAT_Binary_Mind.

View GitHub

An in-browser runtime guard, using WebAssembly and eBPF-inspired techniques, that protects websites against supply-chain tag tampering and ghost data leaks from third-party scripts.

Third-party dependency

If an external CDN is compromised, attackers hijack every client that loads it.

Silent keylogging

Rogue scripts scrape passwords, cards and personal data from the page before submit.

Traditional CSP fails

CSP is static, hard to configure, and powerless when an approved domain turns malicious.

No real-time visibility

Teams cannot see what third-party JavaScript runs in a real user session.

Dynamic DOM isolation

Proxy traps stop untrusted scripts from reading sensitive keystrokes.

On-device ML classifier

A quantized model in a Web Worker analyzes script reads and outbound beacons.

Triage and kill-switch

Spots exfiltration patterns and severs the request mid-execution.

Zero-overhead setup

One 8KB script in the page head gives autonomous defense, no config changes.

Frontend engine

Rust compiled to Wasm, JS Proxy and Object.freeze to lock window primitives.

AI / ML engine

Micro Isolation Forest on ONNX Runtime Web, running in a dedicated Web Worker.

Backend

Python FastAPI for telemetry, Redis for fast threat-domain lookups.

Dashboard

Next.js 15, Tailwind CSS, React Flow dependency map, WebSocket live stream.

Under 1ms

Performance overhead per page.

60 FPS

Main thread stays smooth, detection runs off-thread.

$0

Cloud cost per visitor, detection runs client-side.

Stops Magecart

Blocks form-jacking data theft at the source and supports PCI-DSS 4.0 script security.
